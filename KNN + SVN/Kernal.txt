// **********            Kernel Trick: Intuition          ***********

Problem: SVM uses a straight hyperplane to separate classes, but some datasets are non-linearly separable (ex: concentric circles).

Definition: Kernel Trick is a technique that helps SVM handle non-linear data by calculating similarities in a higher-dimensional feature space without explicitly transforming the data.

Core idea:
-> Original space: Data cannot be separated using a straight line.
-> Higher-dimensional space: Data may become linearly separable.
-> SVM finds a linear hyperplane in the transformed space.
-> This creates a nonlinear decision boundary in the original space.

Example: Concentric Circles (2D to 3D):
-> Original features = (x1, x2)
-> Introduce a new feature: z = x1^2 + x2^2
-> Transformed features = (x1, x2, z)
-> Inner circle points have smaller z values.
-> Outer circle points have larger z values.
-> A plane in 3D can now separate the classes.

Feature Mapping (Φ):
Definition: Feature Mapping transforms original input features into a higher-dimensional representation.

-> Original: x = (x1, x2)
-> Transformed: Φ(x) = (x1, x2, x1^2 + x2^2)

Problem with explicit transformation:
-> Higher dimensions may contain thousands or infinitely many features.
-> Creating and storing these features can be computationally expensive.

Kernel Function:
Definition: Kernel Function calculates the dot product between two points in the transformed feature space without explicitly transforming them.

Formula:
K(xi, xj) = Φ(xi)^T * Φ(xj)

How Kernel Trick works:
-> SVM optimization uses dot products between data points.
-> Instead of explicitly transforming points, we calculate their dot product using a Kernel Function.
-> Avoids explicitly creating higher-dimensional features.
-> Saves computation when a suitable kernel is available.

Types of Kernels:
-> Linear Kernel: Used for approximately linearly separable data.
-> Polynomial Kernel: Captures nonlinear relationships using polynomial combinations of features.
-> RBF Kernel: Measures similarity based on distance; can create complex nonlinear boundaries.

Important points:
-> Kernel Trick helps SVM handle non-linearly separable data.
-> Feature Mapping = Transforming data into a higher-dimensional representation.
-> Kernel Function = Calculates dot products in transformed space.
-> Explicit transformation is not required.
-> Linear separation in higher dimensions can create nonlinear boundaries in original space.

Remember:
Kernel Trick = Higher-dimensional feature space + Implicit transformation + Linear separation in transformed space.

// **********            Kernel Trick in Code: RBF and Polynomial          ***********

Polynomial Kernel:
Definition: Polynomial Kernel calculates similarity between data points using polynomial combinations of their features.

Formula:
K(x, y) = (gamma * x^T*y + r)^d

Parameters:
-> gamma = Kernel coefficient.
-> degree (d) = Controls polynomial degree.
-> coef0 (r) = Independent constant.

Important points:
-> Captures polynomial relationships between features.
-> Higher degree can create more complex decision boundaries.
-> Useful when data contains polynomial patterns.

RBF Kernel (Radial Basis Function):
Definition: RBF Kernel measures similarity between two data points based on their distance.

Formula:
K(x, y) = exp(-gamma * ||x-y||^2)

Core idea:
-> Nearby points = Higher similarity.
-> Faraway points = Lower similarity.
-> Can create complex nonlinear decision boundaries.

Gamma:
Definition: Gamma controls how far the influence of a training data point reaches.

-> High Gamma = Smaller influence area, complex boundary, higher chance of overfitting.
-> Low Gamma = Larger influence area, smoother boundary, higher chance of underfitting.

Important Parameters:
-> C = Controls penalty for margin violations.
-> Gamma = Controls influence range (RBF).
-> Degree = Controls polynomial degree (Polynomial).

Polynomial vs RBF:
-> Polynomial = Polynomial relationships + Degree.
-> RBF = Distance-based similarity + Gamma.

Code: Polynomial Kernel
from sklearn.svm import SVC

model = SVC(kernel="poly", degree=3)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

Code: RBF Kernel
model = SVC(kernel="rbf", gamma="scale", C=1.0)
model.fit(X_train, y_train)
y_pred = model.predict(X_test)

Code: Recommended Pipeline
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.svm import SVC

model = make_pipeline(
    StandardScaler(),
    SVC(kernel="rbf", C=1.0, gamma="scale")
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

Important points:
-> SVC() uses RBF as its default kernel.
-> gamma="scale" is the default gamma setting.
-> Feature scaling is important because SVM uses distances and dot products.
-> Tune C, gamma and degree using cross-validation.

Remember:
Polynomial = Polynomial relationships + Degree.
RBF = Distance-based similarity + Gamma.
C = Controls penalty for margin violations.
