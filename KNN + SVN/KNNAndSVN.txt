// **********            K-Nearest Neighbors (KNN)          ***********

Definition: KNN is a supervised ML algorithm that predicts a new data point using its K nearest training data points.

Core idea: Similar data points are likely to belong to the same class.

How it works:
-> Choose K (number of neighbours).
-> Calculate distance between the new point and existing points.
-> Find K nearest neighbours.
-> Classification = Majority voting.
-> Regression = Average of neighbours.

Distance Metrics:
-> Euclidean: Straight-line distance.
   d = sqrt(sum((x1 - x2)^2))

-> Manhattan: Horizontal + vertical distance.
   d = sum(abs(x1 - x2))

-> Minkowski: Generalized distance.
   p = 1 -> Manhattan
   p = 2 -> Euclidean

Choosing K:
-> Small K = High variance, Low bias -> Overfitting.
-> Large K = Low variance, High bias -> Underfitting.
-> Odd K is preferred for binary classification to reduce ties.

Feature Scaling:
-> KNN is distance-based, so features with larger numerical ranges can dominate distance calculations.
-> Use StandardScaler or MinMaxScaler before applying KNN.

Types:
-> Classification: Majority voting to predict a category.
-> Regression: Average of neighbours to predict a numerical value.

Important characteristics:
-> Instance-Based Learning: Uses stored training examples for prediction.
-> Lazy Learning: No explicit model building; most computation happens during prediction.
-> Non-Parametric: Does not assume a fixed mathematical equation.
-> Curse of Dimensionality: As features increase, distance comparisons become less informative.

Important points:
-> KNN requires storing training data.
-> Prediction can be slow on large datasets.
-> Sensitive to noise, irrelevant features and feature scaling.
-> Choosing the right K is important.

Code:
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler
from sklearn.neighbors import KNeighborsClassifier

model = make_pipeline(
    StandardScaler(),
    KNeighborsClassifier(n_neighbors=5)
)

model.fit(X_train, y_train)
y_pred = model.predict(X_test)

Remember:
KNN = Distance Calculation + K Nearest Neighbours
      + Majority Voting / Average Prediction.




// **********            SVM: Geometric Intuition          ***********

Definition: Support Vector Machine (SVM) is a supervised ML algorithm that finds the best decision boundary to separate different classes.

Core idea: Find a hyperplane that separates classes with the maximum possible margin.

Hyperplane:
-> Decision boundary that separates different classes.
-> 1D = Point
-> 2D = Line
-> 3D = Plane
-> Higher dimensions = Hyperplane

Equation:
w^T * x + b = 0

-> w = Weights (control orientation)
-> x = Input features
-> b = Bias (controls position)

Margin:
Definition: Margin is the distance between the two parallel boundaries passing through the nearest points of both classes.

-> SVM tries to maximize the margin.
-> Larger margin generally helps generalization.
-> Total margin width = 2 / ||w||
-> Distance from hyperplane to each margin boundary = 1 / ||w||

Understanding the Image:
-> Black solid line = Optimal separating hyperplane (w^T*x + b = 0).
-> Upper dashed line = Positive margin boundary (w^T*x + b = 1).
-> Lower dashed line = Negative margin boundary (w^T*x + b = -1).
-> Blue squares = Positive class (+1).
-> Orange circles = Negative class (-1).
-> Circled data points = Support vectors.
-> Distance between the two dashed lines = Maximum margin width.

Support Vectors:
Definition: Support vectors are the data points closest to the decision boundary.

-> They determine the position and orientation of the optimal hyperplane.
-> Moving non-support-vector points generally does not change the boundary.
-> Moving support vectors can change the boundary.

Maximum Margin Classifier:
-> Multiple hyperplanes may separate the classes.
-> SVM chooses the hyperplane with the maximum margin.
-> Maximizing margin = Minimizing ||w||.

Important points:
-> SVM is a supervised learning algorithm.
-> Hyperplane = Decision boundary.
-> Margin = Separation between the two margin boundaries.
-> Support vectors = Closest data points.
-> SVM supports classification (SVC) and regression (SVR).

Remember:
SVM = Best separating hyperplane + Maximum margin + Support vectors.
